# assets/

Drop the fallback screenshot here as:

```
board-fallback.png
```

It should be a clean screenshot of the live bUCR departure board
("bUCR — Próximas salidas"), ideally captured at roughly the same
1280×800 logical size the live iframe slide renders at, so it matches
the framing of the live slide it's a fallback for.

`slides.md` references it with a relative path
(`./assets/board-fallback.png`) from the fallback slide, so no other
change is needed once the PNG is in place — just add the file here.
